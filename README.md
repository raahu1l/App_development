# 📱 App Development Experiments

This repository contains **10+ app development experiments**, each organized in separate folders.  
The projects cover **Dart**, **JavaScript**, **Android**, **Flutter**, **React Native**, and backend integrations like **SQL** and **Firebase**.  
These experiments serve as learning modules for understanding various technologies and app development concepts.

---

## 📂 Folder Structure and Details

### 1. Simple Dart Program
A basic Dart program demonstrating syntax, variables, and I/O operations.  
Useful for beginners to understand Dart fundamentals.

---

### 2. CRUD Operations using JavaScript
Demonstrates **Create, Read, Update, and Delete** operations on an array.  
Helps understand JavaScript data handling and DOM manipulation.

---

### 3. Counter App (Android Studio)
A simple Android app that increments and decrements a counter.  
Introduces **basic UI components**, **event handling**, and **activity lifecycle**.

---

### 4. Calculator using Flutter
A cross-platform calculator built with **Flutter**.  
Covers **widget tree**, **state management**, and **Dart-based UI logic**.

---

### 5. Calculator using React Native
A React Native implementation of a calculator showing **component-based structure**, **styling with Flexbox**, and **event-driven logic**.

---

### 6. GitHub Basic Commands
**Git and GitHub commands** for version control and repository management.

---

### 7. Registration Form UI (Flutter)
A **form-based UI** created using Flutter widgets.  
Includes **validation** and **input field handling** with stateful widgets.

---

### 8. App with Tab and Drawer Navigation
Demonstrates **Flutter’s navigation patterns** using tabs and a drawer layout for smooth user interaction.

---

### 9. SQL Connected To-Do List and Calculator
Integrates **SQL database** for storing to-do items and calculator history.  
Focuses on **CRUD operations** with persistent local storage.

---

### 10. Firebase Connected To-Do and Calculator App
An advanced app using **Firebase** for real-time database integration, authentication, and syncing user data across devices.

---

### 11. Mood Tracker App (Flutter + API Integration)
A Flutter app that allows users to **track and analyze their daily moods**.  
It includes **API integration** for storing user data, retrieving insights, and visualizing emotional patterns.  
Features:
- Daily mood logging with emojis and notes  
- Calendar view for mood tracking  
- Analytics dashboard with mood insights  
- API integration for syncing and data insights  
- Light/Dark mode themes  

Technologies: Flutter, Dart, REST API, Hive/SQLite  

---

### 12. Auth App (Firebase Authentication)
A Flutter app demonstrating **Firebase Authentication** with **Google Sign-In** and **Phone Number verification**.  
It provides a complete example of secure authentication flow and user session handling.  
Features:
- Firebase Authentication integration  
- Google and Phone login  
- Automatic session management  
- Logout and account management  
- Clean and modern Flutter UI  

Technologies: Flutter, Firebase Auth, Google Sign-In, Dart  

---
