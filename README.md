# App_development

App Development Experiments
This repository contains 10 app development experiments, each organized in separate folders. The projects cover Dart, JavaScript, Android, Flutter, React Native, and backend integrations like SQL and Firebase.

Folder Structure and Details
Simple Dart Program
A basic Dart program demonstrating syntax, variables, and I/O operations. Useful for beginners to understand Dart fundamentals.

CRUD Operations using JavaScript
Demonstrates Create, Read, Update, and Delete operations on an array. Helps understand JavaScript data handling and DOM manipulation.

Counter App (Android Studio)
A simple Android app that increments and decrements a counter. Introduces basic UI components, event handling, and activity lifecycle.

Calculator using Flutter
A cross-platform calculator built with Flutter. Covers widget tree, state management, and Dart-based UI logic.

Calculator using React Native
A React Native implementation of a calculator showing component-based structure, styling with Flexbox, and event-driven logic.

GitHub Basic Commands
Contains a markdown file listing essential Git and GitHub commands for version control and repository management.

Registration Form UI (Flutter)
A form-based UI created using Flutter widgets. Includes validation and input field handling with stateful widgets.

App with Tab and Drawer Navigation
Demonstrates Flutter’s navigation patterns using tabs and a drawer layout for smooth user interaction.

SQL Connected To-Do List and Calculator
Integrates SQL database for storing to-do items and calculator history. Focuses on CRUD operations with persistent local storage.

Firebase Connected To-Do and Calculator App
An advanced app using Firebase for real-time database integration, authentication, and syncing user data across devices.

How to Run
Clone the repository using

bash
git clone https://github.com/raahu1l/app-development.git
Navigate to the specific folder you want to run.

Follow the setup instructions provided in each folder’s README.md file.
